# Aeolis.jl

A Julia port of AeoLiS (aeolis-python 3.1.0rc1), the process-based model of supply-limited aeolian sediment
transport, with the SciML problem/integrator/solution interface.

## Invariants that must not be broken

- Results reproduce aeolis-python to round-off. `test/test_reference.jl` runs the cases in `test/data/` (inputs,
  `aeolis.txt` and `reference.nc`, the Python model state after every step) and requires agreement within
  `1e-8` relative plus `1e-10`. A change to the physics that is meant to depart from AeoLiS must be an option
  whose default keeps AeoLiS's behaviour.
- AeoLiS behaviours that look like bugs (index placement of the sparse diagonals, array aliasing, integer
  truncation, `t == 0` tests, `dn`/`ds` naming) are reproduced on purpose and commented where they occur. Do not
  "fix" them without making the fix an option.
- Arrays are `(nx+1, ny+1[, nlayers][, nfractions])`: a Python index `a[j, i, ...]` is `a[i, j, ...]` here, and
  `vec` of a grid has AeoLiS's cell order. Transects are quasi-2-D grids of three identical rows, as in AeoLiS.
- Parameter names are those of AeoLiS configuration files; `PARAMETER_TABLE` in `src/parameters.jl` and
  `STATE_TABLE` in `src/state.jl` are the single sources from which the structs, docs and readers are generated.
- No randomness outside the integrator's `rng` (germination and lateral expansion of vegetation).

## Layout

- `src/Aeolis.jl`: module docstring, imports, includes, exports.
- `src/errors.jl`: `AeolisError` and every exception under it.
- `src/parameters.jl`, `src/state.jl`, `src/config.jl`: parameters, state, configuration files.
- `src/grid.jl`: `AeolisModel`, `setup_model`, grid spacing and rotation.
- One file per process: `wind.jl`, `shear.jl` (spectral shear and separation), `rotation.jl` (wind-aligned grids),
  `threshold.jl`, `transport.jl`, `bed.jl`, `hydro.jl`, `avalanching.jl`, `vegetation.jl`, `fences.jl`,
  `erosion.jl`.
- `src/solvers.jl`: the transport solvers; `src/model.jl`: one time step; `src/problem.jl`: the SciML interface.
- `src/utils.jl`: numerical helpers that reproduce numpy/scipy conventions (sparse diagonals, padding, grids,
  interpolation, filters).
- `ext/AeolisNCDatasetsExt.jl`: `write_netcdf`.

## Commands

```sh
julia --project -e 'using Pkg; Pkg.instantiate(); Pkg.test()'   # the test suite
julia --project=docs docs/make.jl --no-deploy                     # build docs locally
cd vignettes && quarto render && quarto render --to gfm         # render vignettes (PDF needs lualatex + ../../fonts/JuliaMono)
julia scripts/sync_vignettes.jl [--check]                         # copy vignettes into docs/src/tutorials
```

## Files not to edit by hand

- `docs/src/tutorials/` is generated by `scripts/sync_vignettes.jl`.
- `vignettes/*/*.md`, `*.html`, `*.pdf` and `*_files/` are quarto output; edit the `.qmd`.
- `test/data/*/reference.nc` are recorded aeolis-python runs.
- `docs/src/references.bib` and `vignettes/references.bib` are synced copies of a canonical bibliography.

## Style

JuliaFormatter `yas`; docstrings on every exported name (`test/test_docstrings.jl`); the docs build is strict;
typed exceptions in `src/errors.jl` subtyping `AeolisError` with the offending names in the message, invalid
arguments and keywords raise `ArgumentError`, never a bare `error("...")`; seeded RNGs only in tests; no emojis.
