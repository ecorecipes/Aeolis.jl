Parameters and state

Aeolis.AeolisParameters — Type
AeolisParameters(; kwargs...)

The parameters of an AeoLiS model: process switches, input data, grid and time settings, physical constants and numerical options. Every keyword has the name it has in an AeoLiS configuration file; parameter_info lists them with defaults, units and descriptions, and read_config builds parameters from a file.

Values are converted to the parameter's type: numbers to Float64 or Int, strings to Symbol for method names, scalars to one-element vectors for list parameters. An unknown keyword raises an ArgumentError.

Examples

p = AeolisParameters(; xgrid_file=collect(0.0:1.0:100.0), bed_file=zeros(101),
                     wind_file=[0.0 10.0 270.0; 3600.0 10.0 270.0], tstop=3600.0)
p.grain_size   # [0.000225]

Aeolis.AeolisState — Type
AeolisState{T}

The spatial state of an AeoLiS model: one array per variable, of size (nx+1, ny+1), (nx+1, ny+1, nfractions), (nx+1, ny+1, nlayers) or (nx+1, ny+1, nlayers, nfractions). Fields are read as s.zb or s[:zb]; state_info lists the variables with dimensions, units and descriptions.
