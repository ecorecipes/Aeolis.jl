Processes

These functions advance one process of a time step; AeolisProblem's integrator calls them in AeoLiS's order. They are not exported.

Aeolis.setup_model — Function
setup_model(p::AeolisParameters; T=Float64, rng=Random.Xoshiro(0))

The model and its initial state for the parameters p: the grid (a transect becomes a quasi-2-D grid of three identical rows, as in AeoLiS), grid spacing and orientation, bed composition, wind, vegetation and fences. Returns (model, state).

source
Aeolis.aeolis_step! — Function
aeolis_step!(s, m, t, dt, scheme, solver, linsolve)

Advance the state s from time t by one AeoLiS update with requested step dt (-1 for the configured step). Returns the time step used, or nothing when no update was made.

source
Aeolis.set_timestep! — Function
set_timestep!(m, s, dt, scheme)

The time step of the next update: dt when positive, otherwise the dt parameter, limited by the CFL condition for the explicit scheme and by max_bedlevel_change. Returns false for dt < -1, which skips |dt| seconds without computing.

source
Aeolis.initialize_grid! — Function
initialize_grid!(s, m)

Coordinates, cell sizes and areas, and the grid orientation m.alpha (AeoLiS gridparams.initialize). As in AeoLiS, dn is the distance between neighbouring points along x and ds along y; the two are equal on square grids and on transects.

source
Aeolis.grid_rotate! — Function
grid_rotate!(s, m, angle)

Rotate the coordinates and every vector field (shear stress, shear velocity, wind, fluxes, grain velocities) by angle degrees, and add angle to the wind direction (AeoLiS grid_rotate).

source
Aeolis.initialize_wind! — Function
initialize_wind!(s, m)

Prepare the shear computation for two-dimensional grids (transects are quasi-2-D, so they count): the spectral WindShear for method_shear = :fft, a rotated grid for :quasi2d and :duna2d.

source
Aeolis.interpolate_wind! — Function
interpolate_wind!(s, m, t)

Wind speed and direction at time t (the value at the last time not after t, repeating the series beyond its end; directions through their sine and cosine), its components on the grid, and the shear velocity and stress of the undisturbed wind over a bed of roughness z0.

source
Aeolis.roughness_length — Function
roughness_length(s, m)

The roughness length z0 for method_roughness: :constant (z0 = k, as AeoLiS for backward compatibility), :constant_nikuradse (k/30), :mean_grainsize_initial, :mean_grainsize_adaptive, :median_grainsize_adaptive (Sherman and Greenwood 1982) or :vanrijn_strypsteen (van Rijn and Strypsteen 2019). A scalar or a grid.

source
Aeolis.velocity_stress! — Function
velocity_stress!(s, m)

Shear stress from shear velocity: tau = rhoa * ustar^2, with components along the shear velocity.

source
Aeolis.stress_velocity! — Function
stress_velocity!(s, m)

Shear velocity from shear stress: ustar = sqrt(tau / rhoa), with components along the stress.

source
Aeolis.compute_shear! — Function
compute_shear!(s, m)

Perturb the shear stress by the topography (AeoLiS wind.shear): the spectral method of Weng et al. (1991) with a separation bubble for method_shear = :fft, or the rotated-grid methods :quasi2d (Kroy et al. 2002) and :duna2d along wind-aligned transects.

source
Aeolis.WindShear — Type
WindShear(dx, dy, L, l, z0, buffer_width)

The settings of the spectral shear computation: computational cell sizes, the dune length scale L, the inner layer height l, the roughness length z0 (fixed at its initial value, as in AeoLiS) and the width of the buffer around the rotated grid.

source
Aeolis.wind_shear! — Function
wind_shear!(sh, x, y, z, taux, tauy, u0, udir, separation, c, mu_b, taus0, taun0,
            sep_filter_iterations, zsep_y_filter)

The shear stress components over the bed z and the height of the separation bubble, on the input grid (AeoLiS WindShear.__call__). Returns (taux, tauy, hsep).

source
Aeolis.RotationGrid — Type
RotationGrid(dx, dy, buffer_width)

A wind-aligned computational grid with cells dx by dy and a buffer around the input grid.

source
Aeolis.rotated_shear! — Function
rotated_shear!(rg, s, m)

Shear stress perturbed along wind-aligned transects by method_shear (:duna2d, the Duna integral; :quasi2d, Kroy et al. 2002), with the quasi-2-D separation bubble. Returns (tau, zsep, hsep) on the model grid.

source
Aeolis.okin_shear! — Function
okin_shear!(rg, s, m, c1, intercept)

The shear velocity reduced in the lee of vegetation (Okin 2008) along wind-aligned rows, interpolated back to the model grid.

source
Aeolis.compute_threshold! — Function
compute_threshold!(s, m)

The shear velocity threshold of every cell and fraction from the enabled th_* processes, the threshold mask, and the non-erodible layer. With threshold_file the threshold is fixed (only the non-erodible layer applies).

source
Aeolis.threshold_grainsize! — Function
threshold_grainsize!(s, m)

Bagnold's threshold Aa * sqrt((rhog - rhoa) / rhoa * g * d) for every fraction.

source
Aeolis.threshold_moisture! — Function
threshold_moisture!(s, m)

Raise the threshold with the gravimetric moisture content by method_moist_threshold, and make it infinite above max_moist percent volumetric moisture.

source
Aeolis.threshold_salt! — Function
threshold_salt!(s, m)

Raise the threshold with the salt content of the top layer (Nickling and Ecclestone 1981).

source
Aeolis.threshold_sheltering! — Function
threshold_sheltering!(s, m)

Raise the threshold by sheltering from non-erodible roughness elements (Raupach et al. 1993), from the share of top-layer mass in fractions that the wind cannot move.

source
Aeolis.threshold_nelayer! — Function
threshold_nelayer!(s, m)

Make the threshold infinite where the bed is within 0.01 m of the non-erodible layer.

source
Aeolis.grainspeed_duran — Function
grainspeed_duran(s, m)

Grain velocities after Duran et al. (2011), with the effect of bed slopes; also the velocity over a flat bed and the SedTRAILS velocities (zero where the wind is below the threshold). Returns (u0, us, un, u, usST, unST), each (nx+1, ny+1, nfractions).

source
Aeolis.grainspeed_constant! — Function
grainspeed_constant!(s, m)

Grain velocity of 1 m/s along the shear velocity (or along the wind where the shear velocity is zero).

source
Aeolis.equilibrium! — Function
equilibrium!(s, m)

Grain velocities and the saturated sediment concentration Cu (and Cuf with the fluid threshold, Cu0 over a flat bed) by method_transport: :bagnold, :bagnold_gs, :kawamura, :lettau, :dk, :sauermann or :vanrijn_strypsteen, multiplied by accfac.

source
Aeolis.compute_weights — Function
compute_weights(s, m)

Weights of the fractions: from the concentrations in the air relative to saturation (w_air), from the top layer of the bed (w_bed), and their combination by the bed interaction factor bi, normalised. Returns (w, w_air, w_bed).

source
Aeolis.renormalize_weights! — Function
renormalize_weights!(w, ix)

Rescale the weights of fractions ix and above so that all weights sum to one; cells whose weights are all zero get equal weights.

source
Aeolis.solve_trunk — Function
solve_trunk(s, m, dt, alpha, beta, linsolve)

The default AeoLiS solver: an implicit (alpha = 1), Crank-Nicolson (alpha = 0.5) or explicit upwind discretisation solved as a sparse linear system per fraction, iterating the fraction weights until the pickup is supported by the bed.

source
Aeolis.solve_euler_forward — Function
solve_euler_forward(s, m, dt)

The explicit AeoLiS solver (solve_EF): first-order upwind advection on a grid with ghost cells (the first cross-shore column and the ghost column are empty, the lateral edges wrap) plus the pickup limited by the available sediment.

source
Aeolis.solve_pieter — Function
solve_pieter(s, m, dt, alpha, beta, linsolve)

The finite-volume AeoLiS solver (solve_pieter): upwind fluxes on cell faces, the change of concentration solved for iteratively with erosion limited by the bed, and flux, constant, gradient or circular boundaries. At the first step (t == 0) only the weights are set.

source
Aeolis.solve_steady_state — Function
solve_steady_state(s, m, dt)

The steady-state AeoLiS solver (solve_SS with sweep): the concentration in equilibrium with the current wind, found by sweeping the grid in the four upwind directions, with the pickup limited by the top layer; circular boundaries are iterated to convergence.

source
Aeolis.sweep! — Function
sweep!(Ct, Cu, mass, dt, Ts, ds, dn, us, un, w)

AeoLiS's steady-state sweep. Boundary types are passed in Ct's first fraction as in AeoLiS (-1 on the edges for circular, -2 for re-circulating). Indices below follow the Python code (0-based n along y, s along x) and are converted at each access.

source
Aeolis.initialize_bed! — Function
initialize_bed!(s, m)

Bed level, non-erodible layer, layer thickness and the sediment mass per layer and fraction from grain_dist (one distribution, or one row per layer), bedcomp_file or supply_file.

source
Aeolis.mixtoplayer! — Function
mixtoplayer!(s, m)

Mix the layers within the depth of disturbance (facDOD times the wave height for mixing) when process_mixtoplayer is on.

source
Aeolis.wet_bed_reset! — Function
wet_bed_reset!(s, m)

Relax the bed below the total water level towards its initial level with time scale Tbedreset when process_wet_bed_reset is on.

source
Aeolis.update_bed! — Function
update_bed!(s, m)

Remove the pickup from the top layer, shift mass between layers so that layer thicknesses are kept, take new sediment from below the bottom layer with the initial composition, and change the bed level by the net deposition (AeoLiS bed.update). Like AeoLiS this may modify s.pickup where it would remove more sediment than available.

source
Aeolis.average_change! — Function
average_change!(s, m)

Bed level change over the step, per year, and averaged over avg_time (AeoLiS average_change); dzbveg is zero until avg_time has passed.

source
Aeolis.interpolate_hydro! — Function
interpolate_hydro!(s, m, t)

Still and total water levels, wave height and period, the wave height for mixing, and the meteorological conditions at time t; the water level zs is at least the bed.

source
Aeolis.update_hydro! — Function
update_hydro!(s, m, dt, t)

Groundwater (fourth-order Runge-Kutta on the Boussinesq equation in sub-steps of dt / tfac_gw, with runup overheight), moisture (:infiltration or :surf_moisture with soil water retention, optionally with scanning curves), and salt.

source
Aeolis.stockdon_runup — Function
stockdon_runup(Ho, Tp, beta)

Setup, swash and runup (eta, sigma_s, R) of waves of height Ho and period Tp on a beach of slope beta (Stockdon et al. 2006, as in AeoLiS).

source
Aeolis.angle_of_repose! — Function
angle_of_repose!(s, m)

Set the dynamic angle of repose of every cell to theta_dyn.

source
Aeolis.avalanche! — Function
avalanche!(s, m)

Redistribute sand down slopes steeper than the angle of repose (an explicit iteration with a relaxation factor 0.1, at most max_iter_ava sweeps; the downslope gradient of a cell is the steeper one-sided difference, zero on the grid edges and at local minima; fluxes wrap around the grid). The water level is reset to at least the bed; like AeoLiS, the still water level then takes the same values.

source
Aeolis.initialize_vegetation! — Function
initialize_vegetation!(s, m)

Vegetation cover from veg_file (negative values set to zero), height hveg_max * sqrt(cover), and the vegetated cells.

source
Aeolis.vegetation_shear! — Function
vegetation_shear!(s, m)

Reduce the shear velocity by vegetation: Raupach's factor 1 / sqrt(1 + gamma_vegshear * cover), optionally smoothed by a Gaussian filter of width veg_sigma, or Okin's reduction in the lee of each plant on a wind-aligned grid.

source
Aeolis.germinate! — Function
germinate!(s, m)

Germination where the bed is not eroding, and lateral expansion from vegetated neighbours, with yearly probabilities germinate and lateral scaled to the time step. Uses the model's random number generator.

source
Aeolis.grow_vegetation! — Function
grow_vegetation!(s, m)

Vertical growth towards hveg_max at rate V_ver, reduced by burial or erosion away from dzb_opt; plants are removed where flooded or below veg_min_elevation.

source
Aeolis.initialize_fences! — Function
initialize_fences!(s, m)

Fence heights from fence_file and the level of their tops above the initial bed.

source
Aeolis.update_fences! — Function
update_fences!(s, m)

The exposed fence heights (fences lower than 0.1 m or higher than 1.5 m are ignored), and the shear velocity reduced in their lee.

source
Aeolis.dune_erosion! — Function
dune_erosion!(s, m, t)

Erode the dune face along each transect where the total water level (runup times 1.26 plus the tide) exceeds dune_toe_elevation: the eroded volume 4 Cs (TWL - z_toe)^2 Nc, with Nc the number of collisions in the step, is removed by cutting the profile back to a slope of 0.54 beach_slope from the toe.

Numerical helpers

Aeolis.InputArray — Type
InputArray

Type of the parameters that hold input data (grids, time series, masks): nothing or an array. In a configuration file they name a file, which read_config loads.

source
Aeolis.AeolisModel — Type
AeolisModel{T}

Everything a time step needs besides the state: the parameters, the grid dimensions, the forcing series, masks, caches for shear computations, the random number generator and counters. Built by AeolisProblem's integrator; users normally reach it as integ.model.

source
Aeolis.state_dims — Function
state_dims(name, nx, ny, nlayers, nfractions)

The size of the state variable name on a grid of nx by ny cells (nx+1 by ny+1 points).

source
Aeolis.copyto_state! — Function
copyto_state!(dst::AeolisState, src::AeolisState)

Copy every variable of src into dst.

source
Aeolis.parse_value — Function
parse_value(val; dir=".", key=nothing)

The value of a configuration entry: everything after % is a comment; a value with spaces is a list; T/F are booleans; None and an empty value are nothing; the name of an existing file (relative to dir) is loaded with load_array.

source
Aeolis.rotate — Function
rotate(x, y, alpha; origin=(0, 0))

Rotate the points (x, y) by alpha degrees about origin, in the sense AeoLiS uses: the row vector [x y] is multiplied by [cos a -sin a; sin a cos a], so a positive angle turns the points clockwise.

source
Aeolis.normalize_along — Function
normalize_along(x, dim; ref=nothing, fill=0.0)

x divided by its sum along dim (or by ref), with fill where the divisor is zero (numpy-style normalize of AeoLiS).

source
Aeolis.prevent_tiny_negatives! — Function
prevent_tiny_negatives!(x, max_error=1e-10, replacement=0.0)

Replace the values of x in (-max_error, 0) by replacement.

source
Aeolis.apply_mask! — Function
apply_mask!(arr, mask)

Multiply arr by the real part of the complex mask and add its imaginary part. A mask covering the first dimensions of arr is repeated over the rest; a scalar mask applies to every cell.

source
Aeolis.CircularSeries — Type
CircularSeries(t, values)

A linear interpolant of a time series that repeats beyond its range the way AeoLiS's interp_circular does: a time x maps to tmin + mod(x - tmax - 1, tmax - tmin + 1) and is then interpolated linearly, clamped at the ends (numpy.interp).

source
Aeolis.CircularStepSeries — Type
CircularStepSeries(t, values)

The value of a time series at the last time not after x, repeating with period tmax - tmin (AeoLiS's interp_circular_nearest, used for wind).

source
Aeolis.clamped_interp — Function
clamped_interp(x, xp, fp)

Linear interpolation clamped at the ends (numpy.interp).

source
Aeolis.diags — Function
diags(diagonals, offsets, n)

An n by n sparse matrix with diagonals[k] on diagonal offsets[k], placed as scipy.sparse.diags places them: for an offset d >= 0 entry i goes to (i, i+d), for d < 0 to (i-d, i). The AeoLiS solvers rely on this placement, including where a diagonal is taken from a shifted copy of a coefficient array.

source
Aeolis.np_arange — Function
np_arange(start, stop, step)

The points of numpy.arange(start, stop, step) for floats: ceil((stop - start) / step) points start + i * step.

source

exact_grid(xmin, xmax, ymin, ymax, dx, dy)

The regular grid of AeoLiS's get_exact_grid, as (x, y) arrays of size (nx, ny).
